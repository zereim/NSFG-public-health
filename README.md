# NSFG-public-health

2022-2023 NSFG Public Health survey project focused on a topic of my choosing, 
this will include a policy brief and visualizations made with this dataset.

## File Structure

Currently the files are organized into their separate datasets, but eventually
I want to combine some of the datasets to compare fem vs mal vs fem_prg people 
if possible.

Inside each folder there's the dataset, the readme files, the original .zip 
file containing the data and readme, the associated codebooks for each dataset. 

## Goals
1. Discover linkages between contraception usage and SDOHs
2. Look for interesting relationships that I would not expect, and try to 
theorize why this might be the case.
